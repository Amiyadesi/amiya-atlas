# 络笺 Relakeep 0.3.2 使用说明

络笺把账号、邮箱、电话卡、域名、订阅和付款方式连起来。记忆库留在本机，使用本地功能无需注册官网账户。

## 从 Amiya Atlas 升级

关闭旧版，运行 `Relakeep_0.3.2_x64-setup.exe`。安装程序会先卸载旧版应用，再安装到原目录。主密码、记忆库路径和浏览器扩展 ID 保持不变。

首次打开新版，输入原主密码。不要另建记忆库覆盖原文件。记忆库仍在 `%APPDATA%\org.sayori.atlas\atlas.sqlite`；更新前建议在旧版「设置 → 记忆与备份」导出加密备份。

## 自动解锁与账户登录

解锁时可勾选「下次自动解锁」，或在「设置 → 打开与锁定」开启「启动时自动解锁」。关闭这个选项后，每次启动仍需主密码。记忆库一直加密保存；设备解锁密钥由当前 Windows 账户保护。同一 Windows 登录会话中的使用者可打开此库，主密码仍用于备份恢复。

应用内按 `Ctrl + Shift + L` 锁定。启用设备解锁后，在锁定页按相同快捷键即可打开。15 分钟无操作仍自动锁定；手动锁定后不会自动立即重新打开。

侧栏「官网账户」或「设置 → 官网账户」可用系统浏览器完成 GitHub、Google 或官网账户登录与设备授权。登录不会切换模型，也不会代替本地 Vault 的主密码；使用官网云服务需另外在模型设置中选中并保存。

## 日常使用

1. 在首页写一句话，忙的时候点「先存原文」。也可用 `Ctrl + Shift + Space` 打开快速输入。
2. 点「整理预览」，核对新增资产、字段、关系和提醒。点「确认保存」才会修改记忆。
3. 在「记忆」用关键词找回资产，打开详情查看关联。需要自然语言查询时，主动点「理解问题」。

「收件箱」保留尚未确认的原文和提案。错误结果可以编辑、取消单项或重新整理；模型不会自行确认增删。

密码、API Token、SSH 私钥和 CVV 不应写进记忆。秘密继续放在密码库中；络笺只保存外部引用。

## 选择模型

在「设置」明确选择一种模式，应用不会自动切换：

- 本地模型：使用已有 Ollama 或按界面配置本地模型。
- 自带 API：填写你自己的兼容 API 配置，费用直接由对应供应商计费。
- 官网云服务：用系统浏览器登录官网并确认设备授权，回到软件刷新余额。

本地录入、关键词搜索、本地模型和自带 API 不消耗官网额度。本地记忆库不上传官网；云服务仅接收本次输入及完成任务所需的非秘密上下文。

## 官网登录与购买

官网为 `https://atlas.sayori.org`。已完成配置的登录方式才会显示可用入口：邮箱验证码、GitHub、Google。使用不同方式登录时，要在账户页主动关联，系统不会仅凭相同邮箱自动合并账户。

月套餐和加量包均为 300 次，固定价格为 ¥20 / HK$23.50 / US$2.99。月额度每个已付款周期重置、先使用、不累积；加量包永久有效，无需订阅也能购买。

购买会打开 Stripe Checkout。支付回跳页面不直接发额度，账户余额以已验证的付款通知为准。取消月套餐在当前周期结束时生效。

购买后 7 天内、该笔额度完全未用，可以向 `me@sayori.org` 申请退款，提供付款单号。不要发送主密码、记忆库或银行卡完整信息。

收费入口须在实际模型与支付测试通过后开放。入口显示尚未开放时，本地功能继续可用。

## 浏览器捕获

安装目录包含 `extension`。在 Chrome 或 Edge 扩展管理页开启开发者模式，加载该目录。点击「加入络笺」，选择已有身份，再确认创建网站账户和关系。Atlas 必须运行并已解锁。

捕获会移除 URL 的 query、hash 和 userinfo，不读取密码表单、Cookie 或浏览历史，也不在未解锁时保存捕获队列。

## 备份

在「设置 → 记忆与备份」导出加密备份，并在同一入口恢复。备份文件与恢复密码应分开保管。脱敏 JSON 用于分享结构，不包含秘密字段和模型认证信息。

官网账户与本地记忆库是两套存储。官网数据库备份不会替代你的本地记忆库备份。

既有使用细节见 [日常使用](daily-use.md)、[快捷与语音](quick-capture-voice.md) 和 [记忆变更](memory-changes.md)。

## GitHub 私密备份

打开 https://github.com/Amiyadesi/relakeep-vault-template/generate ，创建新仓库时选择 **Private**，再 clone 到本机。不要先 fork 公开仓库。

安装 Git 和 GitHub CLI，执行 `gh auth login`。在络笺导出加密备份，然后在自己私密仓库的终端执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\backup.ps1 -Backup "C:\Users\YourName\Downloads\atlas-encrypted-backup.json"
```

脚本拒绝公开仓库和非加密备份，只提交 `vault/latest.atlas-backup.json`。下次导出后重复命令。恢复时运行 `restore.ps1` 把最新备份放到桌面，再在软件中恢复并输入原主密码。恢复会覆盖当前库，先备份当前数据。

这份模板做手动备份，不自动合并两台电脑的改动；官网 GitHub OAuth 不索取仓库权限。

直接邮箱验证码只接受 Gmail、Outlook/Hotmail/Live、iCloud、QQ/Foxmail、163/126、Yahoo 和 Proton 常见域名。GitHub、Google OAuth 不受这个域名限制。邮箱验证码、GitHub 和 Google 登录现已开放。
