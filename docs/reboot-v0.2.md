# Amiya Atlas 重启：先完成一条记忆链路

Atlas 是本地优先的私人数字记忆层。用户负责自然表达、检查理解并确认；Atlas 负责提出结构化记忆、保留原文、搜索已确认的信息、按需探索关联。

## 当前切片

文本输入 → 保存 Capture 原文 → 模型解析 → Schema 校验与实体匹配 → 可编辑 Proposal → 用户确认 → 加密 SQLite 事务 → 实体详情 / 搜索 / 一跳关联。

- 首页不要求用户先选择类型。
- 待确认的内容只保存在 Capture / Proposal 记录中，不提前创建或更新实体。
- 每项提议由 Atlas 自动附上这次 Capture 的原文，避免模型改写来源；错误输出、断网、锁定不会丢失已保存原文。
- “稍后确认”保留修改过的提案。
- 确认具有幂等性；已变更实体的旧提案必须重新解析，避免覆盖更新。
- 只更新提案提到的属性，保留原有字段、隐私级别与旧模板分类。
- 月份、年份、未知日期按原文精度保存，不猜测具体日期；Atlas 从日期格式计算精度，避免模型给出相互矛盾的两个字段。
- 地区搜索支持美国 / US、日本 / JP 等别名；自然语言搜索产生名称和地区条件，再由本地数据执行。
- Explore 默认一跳，提供关系过滤、缩放、平移和按需展开；画布上限 80 个可见节点。

## 保留的技术基础

沿用仓库的 Tauri 2 + Svelte 5 + TypeScript + Vite，以及逐记录加密 SQLite。此轮不迁移 React、不重写密码学、不导入用户真实清单到代码仓库。

Entity / Field / Relation / Event 继续兼容旧数据；Capture / Proposal / 模型配置作为新增加密记录。首次升级前可在设置中导出加密备份。新版本可读旧库；保存新增记录后，不应使用旧版二进制打开新库。

## 模型边界

`ModelProvider` 只实现 `healthCheck`、`parseCapture` 和 `parseQuery`，没有数据库写入权限。模型返回值由 Zod 和 Rust 独立校验。模型不执行 SQL、工具调用、脚本或数据库命令。

默认 Atlas Local 使用受管理的 Ollama 独立运行时，固定监听 `127.0.0.1:11435`，只加载一份默认模型。Windows x64 在设置中一键下载并准备；现有 Ollama 使用独立设置，不占用或停止用户自己的服务。其他平台可使用现有 Ollama 或兼容 API。

首次下载分为运行时和模型两部分。运行时固定为 Ollama v0.35.0，并校验官方发布的 SHA-256；校验失败不会解压执行。Windows 运行时下载约 1.5 GB，模型 Qwen3.5 2B Q4_K_M 约 1.9 GB，还需要解压空间。模型不塞入安装包。

模型参数：关闭思考、temperature 0、seed 42、上下文 4096、最大输出 1536 token、按可用 CPU 调整到最多 8 个线程、repeat_penalty 1.0、presence_penalty 0；请求简化生成 Schema 后执行完整校验。Schema 或事件引用无效时仅重试一次；仍无效则保留原文，不提交实体。运行时禁用云模型，单请求并行、最多一个已加载模型，闲置十分钟卸载。解锁、保存配置与准备模型后可在后台预热已安装的 Atlas Local 模型。Windows 启动不会弹出终端窗口。

兼容服务可配置 Base URL、API Key、Model，以及 JSON Schema / JSON Object / 仅提示词三种格式。远程接口要求 HTTPS，本机接口可使用 HTTP。远程输入包含当前原文和最多 12 个候选实体的 ID、名称、类型、状态，不包含已有属性、历史原文或 SECRET 实体。API Key 只作为认证发送给配置的模型服务，在桌面加密库中保存，不进入脱敏导出。

模型提出的关联如果缺少可辨认端点，不自动创建占位实体：保留可辨认实体，把未建立的关联明确放入 uncertainty 供用户检查。生命周期中的实体引用仍需通过校验。

## 本轮范围

重启切片完成后，用户要求优化模型、快捷输入与语音；这部分接入同一 Capture / Proposal 流程，见 [快捷与语音](quick-capture-voice.md)。手机端、云同步、插件市场、账户系统、外部服务自动同步、全图渲染仍在范围外。已有浏览器捕获桥保留兼容，暂不继续扩展。

浏览器 `npm run dev` 是临时内存预览，刷新即重置，不等同于桌面 SQLite；真实使用请运行桌面版。

## 第一次试玩

1. 桌面版创建或解锁记忆库。
2. 设置 → Atlas Local → 选择均衡（推荐） → 下载并使用所选模型。
3. 先输入 Saily、SuperGrok，再输入明确的邮箱 / Cloudflare 账号 / 域名关系。
4. 修改错误理解并确认，搜索“美国”，检查生命周期精度和一跳关联。
5. 连续三天真实记录：以是否愿意主动打开为标准，暂不扩大功能范围。

## 开发验证

- 13 项前端逻辑测试、13 项 Rust / SQLite / 音频测试、5 条浏览器交互测试。Windows CI 额外下载并校验真实语音运行时和模型，转写公开中英音频，再构建桌面安装包。
- 真实本地 Qwen3.5 2B Q4_K_M：6 种新记忆、1 次已有实体更新、2 种自然语言筛选通过。测试使用合成邮箱，不引入个人清单。
- 优化后同机 2B Capture 中位时间 5.6 秒，名称 / 地区查询约 1.3–1.4 秒。不是通用性能保证；约数、地区、关系、不确定项需在预览确认。
- Windows x64 首次运行时下载、安装和 GPU 推理需在目标电脑首次试玩；Linux 开发环境不代替该平台的安装验证。
