# Atlas 0.2.2 日常使用

## 第一次打开

1. 从开始菜单打开 Amiya Atlas。已有记忆库输入原来的主密码；新用户按提示创建记忆库。
2. 不配置模型也能记：在首页写一句话，点击「先存原文」。桌面版沿用加密 SQLite 保存到待确认，既不调用模型，也不修改已有实体、关系或提醒。
3. 需要自动整理时，在「设置」选择模型。使用 Atlas Local 时按需下载所选模型；已有模型配置继续保留。也可以配置自己的 Ollama 或兼容服务。

浏览器开发预览只用临时内存，刷新会重置；长期记录请使用桌面版。

## 每天只做三步

**记下。** 按 Ctrl + Shift + Space 打开快速输入，写下账号、项目或决定。忙的时候点「先存原文」；想马上看整理结果就点「整理预览」或按 Ctrl + Enter。等待模型时，待确认会显示已保存的原文和整理状态。关闭快速输入保留本次未提交草稿；锁定清空未提交草稿。

**确认。** 在待确认点击「开始整理」，或打开已经准备好的提案。核对旧值、新值、删除项及其关联，可以取消单项或展开「修改提案」。确认按钮随滚动停留在页面底部；点击「确认保存」才改变记忆。模型出错时原文仍在待确认，可以再次整理。

**找回。** 在「记忆」输入名称、地区或备注关键词，即时过滤；按 Enter 不会触发 AI。例如输入「美国」可以按地区别名搜索。输入「我有哪些日本的东西？」后主动点击「理解问题」，Atlas 会展示名称/地区条件并保留原问题。这里的结果始终来自已确认数据。改写文字或点击 × 会清除旧的 AI 条件。

打开结果查看原文、字段、提醒与关联。点「探索关联」进入关系画布，再返回详情/列表；搜索条件会保留。

## 修改与撤销

- 「测试号码不用了」：提议停用，保留历史。
- 「从 Atlas 删除测试号码」：提议删除，同时列出受影响的关联和提醒。
- 「删除测试号码的月费属性」：只提议删除字段。
- 「取消测试号码的复查提醒」：只提议删除提醒。

这些都是提案，须核对后确认。最近一次确认可以点击「撤销这次变更」，恢复后回到待确认。后续写入（包括保存另一份原文、模型设置或其他变更）会使旧撤销失效，以免覆盖较新的工作。

## 备份与更新

在「设置 → 记忆与备份」导出加密备份，并保存到自己的备份位置。恢复使用同一处的恢复入口。脱敏 JSON 用于分享结构，不包含原文和模型认证信息。升级保留原记忆库与模型配置；写入新版本记录后继续使用新版。

语音和全局快捷键设置见 [快捷与语音](quick-capture-voice.md)，删除边界见 [记忆变更](memory-changes.md)。

## 为什么这样简化

查阅日期：2026-10-11。下面的结论来自作者论文页面和项目官方仓库；设计映射是本项目的取舍，不是论文对 Atlas 的实测。

| 来源                                                                                                                                                                                                                          | 可以借鉴的地方                                                               | 本版选择与限制                                                                                                         |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| [Amershi 等：Guidelines for Human-AI Interaction，CHI 2019](https://www.microsoft.com/en-us/research/publication/guidelines-for-human-ai-interaction/)；[HAX 指南](https://www.microsoft.com/en-us/haxtoolkit/ai-guidelines/) | 将 AI 出错、用户修正与长期控制作为设计的一部分                               | 保留差异、逐项取消、修改和撤销；压缩入口与重复提示，不自动确认                                                         |
| [Buçinca 等：To Trust or to Think，2021](https://arxiv.org/abs/2102.09692)                                                                                                                                                    | 199 人实验中，促使用户思考的设计降低了过度依赖，但更有效的设计主观评价也较低 | 关键变更仍需要核对；不把增加确认弹窗数量当作安全保证。论文任务不同，不能推断本软件的误操作率                           |
| [Kleppmann 等：Local-first software，2019](https://www.inkandswitch.com/essay/local-first/)                                                                                                                                   | 即时操作、可离线工作、数据所有权                                             | 保存原文与关键词搜索不等待模型；本版继续使用现有加密存储，不引入同步或 CRDT                                            |
| [Memos 官方实现](https://github.com/usememos/memos)                                                                                                                                                                           | 先写再整理，通过统一时间线、搜索和筛选找回                                   | 借鉴直接捕获与统一查找入口；保留 Atlas 的实体/关系确认流程，不复制其服务端或分享系统                                   |
| [Graphiti 官方实现](https://github.com/getzep/graphiti)                                                                                                                                                                       | 保留事实来源、时间变化与关系，适合更复杂的记忆检索                           | 当前不引入。它需要 Python、图数据库和模型服务，会增加单机安装与维护成本；现有 SQLite、来源记录和一跳画布已覆盖本次流程 |

选择的是现有 Svelte 界面的渐进简化，没有新增依赖、数据库迁移、模型下载或自动写入能力。新增交互检查覆盖：不调用模型保存原文、整理等待状态、确认前数据不变、关键词回车不调用模型、自然语言条件保留，以及较晚的模型响应不覆盖新搜索。
