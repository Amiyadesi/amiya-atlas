# 络笺 Relakeep 0.9.3

0.9 增加成本地图、账本、客户与订单、项目损益、回顾与投资记录。数据仍保存在本地加密库；同步继续使用自己的服务器或 WebDAV。官网账户与本地库保持独立。

## 升级与安装

升级前，在旧版「设置 → 记忆与备份」导出加密备份。0.9 可以打开旧库，原来的文字费用保留。保存新账本记录后，不要再用 0.4 等旧版程序打开这份库；所有同步设备应一起升级。

- Windows：运行 `Relakeep_0.9.3_x64-setup.exe`，覆盖安装。标识仍是 `org.sayori.atlas`，原库位置不变。
- Android：安装 `Relakeep_0.9.2_arm64.apk`，使用原签名覆盖升级。
- Debian / Ubuntu：`sudo apt install ./Relakeep_0.9.2_amd64.deb`。
- Linux 网页版：解压 `Relakeep_0.9.3_linux-web.tar.gz`，运行 `./relakeep-web`，打开终端给出的链接，默认端口 5011。
- 自建 Docker：首次部署解压 `Relakeep_0.9.2_selfhost.tar.gz`，按包内的 `docs/relakeep-0.4.md` 配置域名和登录。升级时将源码更新到原部署目录，保留原数据卷、`selfhost.env`、身份密钥及 Compose 项目名，沿用原来的 `-p` 和 `-f` 参数执行 `docker compose up -d --build`。不要在新的版本目录直接启动，否则 Compose 可能新建另一份数据卷。不要删除旧数据卷。

## 第一次记账

1. 打开「账本 → 记一笔」，填写金额即可保存。日常支出默认人民币、今天和「未指定账户」，分类按备注识别，也可自己填写。
2. 账户和分类可从建议中选择，也可输入新名称，与流水一起保存。资产库中的银行卡、银行账户及支付宝、微信零钱等钱包会出现在建议中。
3. 「一句话记账」支持「早餐3.9，午餐22.5，打车11.07」等简写。预览中可修改类型、金额、币种、日期、账户、分类和备注，也能添加或移除一笔；无需 AI 模型。
4. 需要管理余额时，可在「账户」添加资金账户，再用「期初余额」或「对账」录入已有余额。项目、手续费和对方在「更多」中。

「AI 整理」使用设置中选择的本地模型、BYOK 或官网云服务。官网云整理和智能查询沿用收费额度；本地表单、关键词筛选和本地计算免费。

未填写账户不阻止日常收支保存。转账需选择转出和转入账户；金额不确定时在预览中核对。未来计划和未发生的收支不自动记账。

## 改错与对账

流水写入后不能直接修改或删除。点流水的「冲正」生成完整反向记录；手机点开该条流水也能操作。最近一次确认可用浮动提示中的「撤销这次变更」，流水历史仍保留。

「账户 → 对账」填写实际余额和差额原因。负债账户填写正数欠款。确认后生成调整记录；往已对账日期补记时会再次确认。

默认隐藏普通流水分录。「账本 → 账户 → 账本设置 → 显示分录」可以展开查看。

## 成本、项目与订单

- 编辑订阅、服务器、域名或 AI 账户，填写金额类型的 `fee` 和计费周期。年费、季费折算月度，按量计费单列，不跨币种相加。旧 `cost` 文字可在资源成本页生成转换提案。
- 「项目 → 分摊成本」设置资源、项目比例和生效日期；未分配的部分计为闲置。更改已有分摊时新增生效版本，旧月份保留原比例。
- 新建「客户 / Client」与「接单 / Order」，填写报价、交付日期、所属项目，建立 `INVOICED_TO` 客户关联。订单旁点「收款」，收入流水会关联该订单，自动计算已收和应收。
- 收入可填写平台手续费。在账本设置选择预留账户与自定比例后，收入表单会加入预留金额。程序不提供默认税率。
- 「项目 → 经营项目」勾选明确用于商业经营的项目后，才会出现在项目损益中。普通项目仍可记录成本；损益区分收入、直接成本和分摊成本。

## 资产关联与标签

1. 新建或编辑账号时，先选择「注册 / 登录方式」：邮箱、电话卡或已有平台账号。可直接在当前表单新建关联对象，选择类型后与主记录一起保存。
2. 电话卡选择运营商，银行卡选择银行，域名选择注册商；平台 / 服务商与自己的账号分开记录。同一个平台可连接多张卡或多个账号。
3. 服务和项目可同时关联访问域名、部署服务器、源码仓库及多个上游账号 / 额度来源。「更多关联」保留其他关系类型。
4. 旧数据到「记忆 → 从字段补全关联」预览并勾选保存。只使用已有明确字段；遇到重名对象，请在单条记录中选择。原文字字段保留。
5. 「待补关联」筛选缺少来源或有字段待关联的记录。暂时不知道来源时，可「存为待整理」，以后再补。
6. 详情点「收藏」，图中球体出现星星。编辑标签可选图案，也能直接输入「🦊 私人项目」等自定义标签；连线越多，球体越大，关系筛选不会改变其大小。

## 图谱与回顾

「关系图 → 关系」默认显示全库，包含没有连线的资产。拖动旋转，滚轮或双指缩放，点击「全屏」放大。单击球体或从搜索补全中选择资产，都会聚焦该资产、展开邻居并将无关资产移到外围，同时打开详情侧栏。侧栏可查看入向和出向关系，点「查看详情」编辑或收藏。箭头由关系来源指向目标。

颜色对应账号、通信、资金、服务、设施、项目等分类。总览会减少文字重叠，缩放和选中后显示相关名称；这不会减少加载的资产数。SECRET 条目和关系不显示。开发预览已用 1,200 个脱敏资产和 849 条关系检查全库显示、搜索、聚焦、旋转与全屏；不代表所有手机均有相同性能。

「关系图 → 金钱」按币种查看资源月成本、分摊连线与项目损益。点击节点查看关联流水，账本流水本身不会变成图谱节点。

「账本 → 回顾」提供月度或最近七天汇总、简单预算、续费差额和钱流图。自然语言查询先产生筛选条件，再由本机计算金额与项目分摊；只知道月份的流水不会被猜测分配到某一周。

## 投资记录

1. 在账户页添加持仓账户（例如 BTC）、资金账户（例如 USD），并保留一个无固定币种的「期初与调整」账户用于清算。
2. 在「投资 → 记录交易」填买卖、数量、成交总额、手续费、账户和日期，预览后保存。
3. 持仓数量、成本批次和已实现盈亏由流水计算；默认 FIFO，可在账本设置改为 LIFO。同一持仓账户使用一种计价币种。
4. 打开「投资」会自动获取 Coinbase 支持的币种价格和汇率，并在页面打开期间每分钟刷新；显示来源与更新时间，可点「刷新行情」。持仓估值和净资产折算优先使用本次行情；请求失败会显示错误，仍可「录入价格」补充自己的数据。
5. 「交易计划」记录入场、目标、止损、冷静期与复盘。手动保存的价格触及止损时，计划进入止损状态并产生复盘待办。实时行情只用于估值，不生成交易或修改已记账金额。

Android APK、Debian 桌面包与首次部署归档目前仍是 0.9.2；上述 0.9.3 交互可先在个人网页版使用。

## 导出与同步

完整迁移用加密备份；目标设备恢复时输入原库主密码。恢复会替换目标库。自动同步包含财务记录，独立追加流水取并集，同一幂等键不重复入账，冲突会明确报错。

网页或桌面可在「设置 → 官网账户」完成官网授权，选择云模型、查看余额和购买套餐。云服务仍按已付款额度使用。个人服务器再到「服务器登录」关联同一官网账户；其他设备登录该账户后，在同步设置选择该服务器。只关联元数据，资产仍由自己的服务器保存。

不使用官网账户时，可在个人服务器的「设置 → 服务器登录 → 同步密钥」生成密钥，在客户端「自建服务器」填地址并选择使用密钥。密钥只显示一次，可按设备撤销。首次连接不同记忆库仍需确认采用哪份库并输入原库主密码。

账本页可按当前筛选导出明文 CSV，导出前确认；文件包含账户、金额和备注，请按财务数据保存。脱敏 JSON 排除账本、金额字段和备注，不能用于完整恢复。

新版会保留不认识的加密记录类型，避免未来扩展被同步吞掉；该能力不能补到已发布的旧二进制中。

## 验证与仍待实用验收

0.9.3 的 54 项账本与行情检查通过，覆盖不选账户记账、连续草稿保存、资产账户关联、手填账户分类、商业项目标记、固定精度价格和汇率换算。浏览器演示完成多笔餐饮与打车保存、账户与分类编辑、转账账户编辑、自动行情和点击球体聚焦；Svelte 检查与服务器类型检查通过。
