# 快捷输入、本地语音与模型优化

## 日常使用

Atlas 运行时，Ctrl + Shift + Space 打开快速输入；Ctrl + Alt + V 读取一次剪贴板；Ctrl + Alt + R 在已准备语音模型且记忆库解锁时打开录音。macOS 快捷输入 / 剪贴板使用 Command 替代 Ctrl；内置语音安装目前仅支持 Windows x64。

输入框与快速窗口共享本次草稿。关闭快速窗口不提交也不清空文字，锁定则清空私有内存。Ctrl + Enter 先保存 Capture 原文，再请求模型形成待确认 Proposal；只有确认才能提交实体、关系和事件。快捷键不会自动提交剪贴板。锁定时只显示解锁入口，解锁后需再次触发记录。全局快捷键可在设置中关闭，冲突不会导致应用启动失败。

默认采用多语言 Whisper Small Q5_1，适合中文与夹杂英文名称的短句。190,085,487 字节模型和 8,573,270 字节 Windows CPU 运行时按需下载，均校验固定 SHA-256；模型 URL 固定到 Hugging Face 提交，运行时固定到官方 b5130 发布（v1.9.4 对应构建）。支持自动识别或明确指定中文 / 英文 / 日文。

官方 Windows 语音运行时依赖 Microsoft Visual C++ v14 x64 DLL。设置页检查缺少的依赖并提供 [Microsoft 官方下载](https://aka.ms/vc14/vc_redist.x64.exe)；安装后可重新检查。Atlas 不静默安装系统运行库。版本应符合 [Microsoft 的运行库兼容要求](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。

浏览器 WebAudio 只负责录音、混合为单声道和重采样；输出 16 kHz / 16 位 PCM WAV。Rust 独立检查 WAV 结构、时长（0.35–60 秒）和静音，调用本地 CLI 输出结构化转写。转写回到可编辑文字，核对后走普通 Capture 流程，来源记录为 voice。没有单独的语音数据库，也不保留音频。

取消 / 锁定可停止麦克风、取消等待中的授权结果、终止本次转写子进程并清理临时文件；转写超时为 120 秒。临时目录由进程持有，完成、取消、错误均删除。进程意外崩溃或系统断电可能遗留临时目录，应按普通本机文件处理。浏览器预览只提供临时内存数据，内置转写需使用桌面版。

系统听写由操作系统管理。Atlas 内置语音不上传录音；用户若配置远程记忆模型，点击整理后会发送文字与有限的匹配上下文，沿用原有远程模型边界。

## 实测后的默认选择

使用同一 CPU 开发环境、相同提示词与 Schema、temperature 0、seed 42、4096 上下文，关闭思考；先加载模型，7 条 Capture 加 2 条查询。Saily / SuperGrok / Cloudflare 等名称来自项目验证目标，邮箱用合成地址。断言检查类型、地区、费用、日期精度、可辨认关系、已有实体更新，以及不创造未提供身份的账号；不是完整准确率评测。

| 模型                      | 大小约数 | 通过指定断言 | Capture 中位耗时               |
| ------------------------- | -------- | ------------ | ------------------------------ |
| Qwen3.5 0.8B Q8_0         | 1.0 GB   | 4 / 9        | 3.2 秒，含失败结果，不用于推荐 |
| Qwen3.5 2B Q4_K_M，4 线程 | 1.9 GB   | 9 / 9        | 7.0 秒                         |
| Qwen3.5 2B Q4_K_M，8 线程 | 1.9 GB   | 9 / 9        | 5.6 秒                         |
| Qwen3.5 4B Q4_K_M，8 线程 | 3.4 GB   | 9 / 9        | 13.7 秒                        |

0.8B 漏掉地区、把更新误做成新建，并为单项订阅创造多余实体；不在受管理的本地选项中提供。4B 在此小样本没有带来更高通过率且更慢，因此默认保持 2B，4B 可选供用户自行比较。较新的 [Qwen3.8](https://ollama.com/library/qwen3.8) 当前为约 18 GB 的 27B，[Gemma 4 E2B](https://ollama.com/library/gemma4) 下载约 4.6 GB 起，本轮没有下载或评测它们。

Atlas Local 线程数由 Rust 按可用 CPU 限制在 1–8，解锁或更换配置后预热已安装模型，保活十分钟。浏览器 / SSR 验证使用固定 8 线程；4 线程对照通过评测脚本覆盖。首次系统提示词预填仍需时间，GPU、硬件、描述长度与校验重试会影响延迟；这些耗时不代表所有电脑。

复现前先在 `127.0.0.1:11435` 准备对应模型：

```powershell
$env:ATLAS_EVAL_MODEL = 'qwen3.5:2b-q4_K_M'
$env:ATLAS_EVAL_THREADS = '8'
node scripts/evaluate-local.mjs
```

评测在忽略的 `qa-artifacts/evaluation-*` 目录输出提案与报告。任一断言失败会以非零状态退出。

## 验证范围

前端测试覆盖音频编码与大小边界、快速窗口草稿、按需剪贴板、快捷整理仍须确认、锁定、模型切换与布局。Chromium 模拟麦克风通过真实 AudioWorklet 和重采样管线，验证停止 / 取消释放音轨；Rust 覆盖 WAV 验证、静音、无效响应、取消，以及 voice 原文的加密存储和备份恢复。

真实 Whisper CPU 运行时已转写公开中英音频，中文采用 sherpa 项目维护者的 [公开样例](https://huggingface.co/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17/tree/2365baeacb507f821a0c8120fcee3d484dba7a07/test_wavs)。Windows CI 通过原生下载 / 校验 / 安装 / 转写路径验证同样音频。实际电脑的全局热键占用、麦克风权限、蓝牙设备、个人发音及英文资产名仍需要第一次试玩确认。

升级到 0.2.0 前导出加密备份。此版支持原有 text 捕获，并增加 clipboard / voice 来源与 4B 配置；保存这些记录后，旧版本的校验器不能读取它们，应继续使用新版。
